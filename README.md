# Bright Coffee Shop Sales Analysis

## Project Overview

This project analyzes sales data from a coffee shop to uncover insights into revenue, product performance, and customer trends.
The goal is to use data analysis and visualization to support better business decision-making.

## Objectives

* Analyze total revenue generated
* Identify top-performing product categories
* Understand sales patterns and trends
* Visualize key insights using graphs

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook / Kaggle

## Dataset

The dataset contains information about:

* Product categories
* Sales transactions
* Total amount spent

## Key Analysis Performed

* Data cleaning and preprocessing
* Grouping data by product category
* Calculating total revenue per category
* Creating bar charts to visualize revenue distribution

## Sample Insight

* Certain product categories generate significantly higher revenue than others, helping the business focus on high-performing items.

## How to Run the Project

1. Install required libraries:

   ```bash
   pip install pandas numpy matplotlib
   ```
2. Open the notebook in Jupyter or Kaggle
3. Run all cells from top to bottom
